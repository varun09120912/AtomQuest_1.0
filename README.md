# AtomQuest_1.0

A complete, modern, and interactive Goal Setting & Tracking Portal built for the AtomQuest Hackathon.

## Features Included
- Employee Goal setting and tracking workflow
- Manager approval and review modules
- Shared KPI push capabilities
- Check-in functionality for Quarterly goals
- Real-time Analytics Module showing Orgz-level metrics
- Rule-based mock Escalation logs

## Running Locally
Run the following commands:
```bash
npm install
npm run dev
```
